# Seasons (part 2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the parts that make seasons work:
- Admin-managed seasons per group.
- Four season titles shown festively on the group page.
- A "Vorige seizoenen" screen.
- A Ranglijst with a season picker, stat buttons and tap-to-unfold rows.

**Architecture:** The server stores only season boundaries: implicit season 1 plus `seasons` rows. They're delivered with each group in `GET /groups` and `GET /admin/groups`. The phone assigns games to seasons by `started_at` instant and computes titles and the Ranglijst from cached games. Nothing about titles is stored.

**Tech Stack:** PHP 8.4 + PDO/MySQL 8.4 + PHPUnit 11 (`api/`); Vite + Preact + TS + Vitest + Dexie (`pwa/`).

**Spec:** `docs/superpowers/specs/2026-11-27-seasons-design.md` (Part 2, Title rules, Clarifications)

**Depends on:** `docs/superpowers/plans/2026-11-27-fold-count.md` being merged first (`PlayerStats.folds`, `GamePlayer.fold_count`).

## Global Constraints

- **Out of scope:** no changes under `ToepScoreTracker/`. No new Playwright e2e tests.
- **Must stay green:** `npm test`, `npm run build` (in `pwa/`) and the full PHPUnit suite. PHPUnit runs with `PATH=/c/Users/t.wezeman/AppData/Local/Programs/DockerDesktop/resources/bin:$PATH docker compose exec -T php sh -c "cd api && vendor/bin/phpunit"`.
- **Migration `api/migrations/006_seasons.sql`:**
  - Adds `game_groups.first_season_name VARCHAR(40) NULL`.
  - Creates `seasons` with these columns:
    - `id INT UNSIGNED NOT NULL AUTO_INCREMENT PRIMARY KEY`
    - `group_id INT UNSIGNED NOT NULL`
    - `name VARCHAR(40) NULL`
    - `starts_at DATETIME NOT NULL` (UTC)
  - Plus `UNIQUE KEY uq_seasons_group_start (group_id, starts_at)` and `CONSTRAINT fk_seasons_group FOREIGN KEY (group_id) REFERENCES game_groups (id)`, using the engine and charset of 001.
- **Season state JSON** (in every group from `GET /groups`, in `GET /admin/groups`, and returned by every season endpoint): `{"first_season_name": string|null, "seasons": [{"id": int, "name": string|null, "starts_at": ISO-with-offset}]}`, ascending by `starts_at`.
- **Admin endpoints** (route auth `'admin'`):
  - `POST /admin/groups/{id}/seasons` with `{name?, starts_at?}` returns 201 with the season state.
  - `PATCH /admin/seasons/{id}` with `{name?, starts_at?}` returns 200 with the season state.
  - `DELETE /admin/seasons/{id}` returns 200 with the season state.
  - `PATCH /admin/groups/{id}/first-season` with `{name}` returns 200 with the season state.
- **Validation:**
  - Names are trimmed, 1–40 characters. `null` or `""` resets to the default.
  - `starts_at` must be ISO with an offset, parsed like `Validate::parseStartedAt`.
  - "Not in the future" means ≤ server now + 5 minutes.
  - A new season must start after the latest existing start. An edited start must stay strictly between its neighbours' starts.
  - Errors are 422 `validation_failed` with Dutch messages in the existing style (e.g. `'Ongeldige invoer: startdatum moet na het vorige seizoen liggen.'`). An unknown group or season gives 404.
- **Merging groups:** `mergeGroups` deletes the source group's `seasons` rows before deleting the source group.
- **Default label:** `Seizoen <n>`, where n is 1 for the implicit season and 2… for rows in order.
- **UI text (Dutch, exact):**
  - Pills: `LOOPT NOG`, `AFGELOPEN`.
  - Banner: `KAMPIOEN <SEASON LABEL UPPERCASE>`, or `Nog geen kampioen` when there's no Kampioen.
  - Count text: `<n> keer gewonnen` for the Kampioen, `<n>×` for the others.
  - Title rows: `💀 Anita`, `🃏 Boer`, `👑 Paskoning`.
  - Season lines: `<label> · loopt sinds <dag maand>` and `<label> · <dag maand> – <dag maand>`.
  - Link: `Vorige seizoenen ›`.
  - Stat buttons: `Gewonnen`, `%`, `Boeren`, `Anita's`, `Gepast`, `Duur`.
  - Picker option: `Alles`.
  - Admin: `Seizoenen`, `Nieuw seizoen starten`, `Hernoemen`, `Startdatum wijzigen`, `Verwijderen`.
  - Confirmation: `<label> afsluiten en seizoen <n+1> starten?`
- **Confetti:** falls only inside the Kampioen banner (clipped, behind the text) for about 3 s on each mount, only in the just-ended view. It's off under `prefers-reduced-motion: reduce`.
- **Approved mockups:** the HTML files in `.superpowers/brainstorm/1315-1795768710/content/` (`ranglijst-layout-v2.html`, `group-titles-v3.html`) are the visual reference. They aren't in git; read them for layout and colours.
- **Season 1 dates:** season 1 has no stored start. Wherever a start date is displayed, use its oldest game's `started_at`. With no games, leave out the date part (just `<label>` or `<label> · loopt nog`).
- **Old caches:** a `CachedGroup` without `seasons`/`firstSeasonName` (cached before this update) behaves as `[]`/`null`.

## Review Focus

1. **Game exactly at a season start** belongs to the new season (`start ≤ t < end`). → Task 2 test `game at the boundary belongs to the later season`.
2. **Mixed offsets:** `started_at` values with different offsets compare as instants, not strings. → Task 2 test `compares instants across offsets`.
3. **Kampioen tie on wins:** broken by win %, then shared. → Task 2 tests `kampioen tie broken by win rate` and `kampioen shared when wins and rate tie`.
4. **Backdated new season** that already has games skips the just-ended view, and so does an ended season without games. → Task 2 tests `no just-ended view when the running season has games` and `no just-ended view when the ended season had no games`.
5. **Admin edits a start date past a neighbour:** 422 and nothing changes. → Task 1 test `test_patch_start_must_stay_between_neighbours`.

### Task 2: PWA season model

**Files:**

- Modify: `pwa/src/types.ts` (`Group` gets `first_season_name: string | null; seasons: ApiSeason[]`; `CachedGroup` gets optional `seasons?: ApiSeason[]; firstSeasonName?: string | null`; `export interface ApiSeason { id: number; name: string | null; starts_at: string }`), `pwa/src/sync/refresh.ts` (copy both fields into the cached group), `pwa/src/util/format.ts` (+ `formatDay`), `pwa/tests/unit/sync.test.ts`, `pwa/tests/unit/format.test.ts`

**Interfaces:**
- Consumes: `leaderboard()` / `PlayerStats` from `stats.ts` (with `folds` and `anita`).
- Produces (in `seasons.ts`):
  - `interface Season { id: number | null; number: number; label: string; start: number | null; end: number | null }`. `id` is null for implicit season 1, and `start`/`end` are epoch ms, with null meaning unbounded.
  - `seasonsOf(g: { seasons?: ApiSeason[]; firstSeasonName?: string | null }): Season[]`. It always has ≥ 1 entry, and the last one is the running season.
  - `gamesIn(s: Season, games: Game[]): Game[]`
  - `interface Title { names: string[]; count: number }`
  - `interface SeasonTitles { kampioen: Title | null; anita: Title | null; boer: Title | null; paskoning: Title | null }`
  - `titles(games: Game[]): SeasonTitles`. Names follow `leaderboard()` display names, ordered `nl` alphabetically.
  - `type GroupPageView = { kind: 'justEnded'; ended: Season; running: Season; titles: SeasonTitles } | { kind: 'running'; running: Season; titles: SeasonTitles }`
  - `groupPageView(seasons: Season[], games: Game[]): GroupPageView`
  - `pastSeasons(seasons: Season[], games: Game[]): { season: Season; titles: SeasonTitles }[]`. These are ended seasons with ≥ 1 game, newest first.
- Produces (in `format.ts`): `formatDay(ms: number): string`, `nl-NL` day + long month, e.g. `3 maart`.
