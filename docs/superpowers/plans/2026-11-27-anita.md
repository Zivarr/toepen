# Anita Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Record the first player knocked out of each game (the "Anita") and show it in the game, on the results screen and on the Ranglijst.

**Architecture:** A per-player boolean `is_anita` flows the same way `boer_count` already does: engine state → `toUpload` → API validation → `game_players` column → `GET` responses → `stats.ts` → screens.

**Tech Stack:** PHP 8.4 + PDO/MySQL 8.4 + PHPUnit 11 (`api/`); Vite + Preact + TS + Vitest (`pwa/`).

**Spec:** `docs/superpowers/specs/2026-11-27-anita-design.md`

## Global Constraints

- No changes under `ToepScoreTracker/` (Android is abandoned).
- First-knockout toast, exact: `` `${name} heeft verloren en is de Anita!` ``. Later knockouts keep `` `${name} heeft verloren!` ``.
- Ranglijst column header: `Anita's`, placed right after `Boeren`. Results tag text: `Anita`.
- `is_anita` is optional on upload and defaults to `false`. Games already queued in the outbox, and pending sync requests, have no such field and must still be accepted.
- PWA reads must treat a missing `is_anita` (games cached in IndexedDB before this update) as `false`.
- No new Playwright e2e tests (the owner tests live). Keep `npm test`, `npm run build` (in `pwa/`) and the full PHPUnit suite green.
- PHPUnit runs as `docker compose exec -T php sh -c "cd api && vendor/bin/phpunit"`. Docker bin: `/c/Users/t.wezeman/AppData/Local/Programs/DockerDesktop/resources/bin`.

## Review Focus

1. Undo of the first knockout: Anita must go back to `null`, and the next knockout becomes the Anita. → Task 1 test `undo of the first knockout clears anita`.
2. A sync request stored before migration 004 (games without `is_anita`) approved afterwards must not 422. → Task 2 test `test_missing_is_anita_defaults_false`.
3. Games cached locally before the update (no `is_anita`) must not crash or count in stats. → Task 3 test `missing is_anita counts as zero`.
4. "Eindig spel" after one knockout keeps that Anita; before any knockout there is none. → Task 1 tests.
5. The last knockout that ends a 2-player game is also the first one: that player is the Anita, and the toast says so. → Task 1 test `two players: the only knockout is the anita`.
